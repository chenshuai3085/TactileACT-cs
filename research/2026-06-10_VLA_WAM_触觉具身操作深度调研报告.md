# 2026-06-10 VLA/WAM/触觉具身操作深度调研报告

## 一句话结论

当前最值得投入的方向不是“给 VLA 多拼一个触觉输入”，而是做 **tactile/force consequence-aware VLA/WAM**：让模型在动作执行前预测未来触觉/力后果，用接触质量能量函数评估这些后果，并在推理时进行动作筛选、梯度修正、失败恢复和安全门控。

对我们来说，最合适的论文主线是：

> **Tac-WAM / PTG-VLA: Proactive Tactile Consequence Guidance for Contact-Rich Manipulation**
>
> 利用已有真机触觉数据、TactileVAE、Foresight、TacQualityEnergy/CQF，把触觉从“被动观测模态”提升为“动作后果预测器 + 接触质量 critic + 执行时修正器”。

这个方向同时满足：

1. **足够新**：2026-06-07/08 最新论文集中爆发 Dream-Tac、FAWAM、TORL-VLA、AHA-WAM、MemoryVLA++ 等；
2. **符合热点**：VLA 正在向 WAM、future imagination、failure recovery、runtime safety/filtering 迁移；
3. **适合我们的资源**：我们有真机、有触觉、有接触任务数据、有已实现的 tactile foresight 和 scorer/guidance；
4. **容易 work**：不需要训练大规模 foundation VLA，从现有 DP/ACT/VLA action head 上做 lightweight guidance/refinement；
5. **容易讲出差异**：相比 Dream-Tac/FAWAM 的大模型联合生成，我们主打轻量、可插拔、可微的 tactile consequence critic。

## 1. 调研范围与筛选标准

时间范围：

1. 核心关注 2026-05 到 2026-06，尤其 2026-06-01 到 2026-06-10；
2. 保留少量 2026-02 到 2026-04 的相关触觉世界模型、ReTac-ACT、ForceVLA2 等作为背景；
3. 不重点讨论 2025 及更早的通用 VLA，除非它们是基座模型或 baseline。

筛选标准：

1. 是否是 VLA / WAM / manipulation 主线；
2. 是否与接触、触觉、力、world model、future prediction、failure recovery 强相关；
3. 是否能利用我们的真机和触觉数据；
4. 是否能在 1-2 个月内做出可见实验结果；
5. 是否能形成有区别于最新论文的可发表贡献。

### 2.2 大趋势判断

最近两周的主线不是“更大的 VLA 直接输出动作”，而是：

1. **World Action Model 化**：
   - 让 action generation 和 future state prediction 绑定；
   - 未来视觉/触觉/力不只是辅助任务，而是动作选择依据。
2. **Runtime intervention 化**：
   - 训练好 VLA 后，用 safety filter、failure recovery、residual correction 在执行时修正；
   - 小模型、probe、critic、CBF、residual policy 都成为热点。
3. **接触物理显式化**：
   - force/tactile 不再只作为 observation；
   - 最新工作强调 future wrench/tactile prediction、contact-aware attention、closed-loop correction。
4. **实时闭环化**：
   - AHA-WAM、Fast-dVLA、Flash-WAM、vla.cpp 都在解决推理速度；
   - 对接触任务，频率和闭环修正比离线成功率更重要。

## 3. 重点论文分析

### 3.1 Dream-Tac: Unified Tactile World Action Model

arXiv: `2606.08737`
代码：https://github.com/LYFCLOUDFAN/Dream-Tac

核心：

1. 在同一 latent diffusion/WAM 框架里联合建模 future visual、future tactile、actions；
2. 提出 contact-gated visuotactile fusion；
3. 提出 contact-aware attention bias，根据触觉变化增强对 tactile token 的关注；
4. 做六个真机接触任务：Pick Baguette、Insert USB、Clean Whiteboard、Peel Cucumber、Play Mahjong、Cut Banana。

结果：

1. 平均成功率 83.3%；
2. Visual WAM 51.7%；
3. Visuo-tactile WAM 74.2%；
4. Visuo-tactile WAM + bias 83.3%；
5. 在 Clean Whiteboard、Cut Banana、Play Mahjong 等任务上明显优于 pi0/pi0.5/ForceVLA/Cosmos Policy。

对我们的启发：

1. 触觉 WAM 是非常新的热点；
2. 单纯“触觉融合”已被 Dream-Tac 覆盖，我们不能只重复；
3. Dream-Tac 是重模型联合生成路线，我们可以走轻量路线：
   - 不生成完整 future image；
   - 只预测接触相关 tactile latent / force proxy；
   - 用 scorer/energy 做动作候选筛选或可微修正。

我们的差异点：

| Dream-Tac | 我们可做 |
|---|---|
| future visual + tactile + action joint generation | 只预测 contact consequence，轻量、实时 |
| contact-aware attention bias | contact quality energy / tactile critic |
| 训练一个完整 tactile WAM | 可插拔到 DP/ACT/VLA action head |
| 更像 representation/fusion | 更像 action selection / correction / safety |

### 3.2 FAWAM: Force-Aware WAM for Closed-Loop Contact Manipulation

arXiv: `2606.08555`

核心：

1. force signals 在 perception、prediction、execution 三层使用；
2. 历史 6D wrench 调制 action generation；
3. joint action-force prediction；
4. predicted wrench reference 与 real wrench feedback 的误差进入 residual corrector。

结果：

1. 四个真机任务：Erase Whiteboard、Peel Cucumber、Pivot Box、Wipe Vase；
2. 每任务 90 demos，residual corrector 额外 20 human-intervention episodes；
3. π0.5 平均 47.5%，GE-Act 48.75%，ForceVLA/TA-VLA 63.75%；
4. FAWAM w/o residual 73.75%，FAWAM full 85%；
5. 消融显示：只加 force obs 56.25%，joint action-force prediction 73.75%，full 85%。

对我们的启发：

1. “未来接触预测 + 执行时 correction”是很强论文叙事；
2. 只把 force/tactile 当 observation 的收益有限；
3. 预测未来 force/tactile 应该用于 action correction，而不只是辅助 loss。

我们的差异点：

| FAWAM | 我们可做 |
|---|---|
| wrist 6-axis force/torque | GelSight/marker tactile latent + 可选 force proxy |
| residual corrector 需要 human intervention episodes | 用已有 negative/perturbation/quality labels 和 scorer energy 做无需额外 intervention 的 refinement |
| predicted wrench reference | predicted tactile quality / contact risk reference |
| task-specific force-aware WAM | task-conditioned tactile quality energy 可跨插座/黑板 |

### 3.3 TORL-VLA: Tactile Guided Online RL

arXiv: `2606.09337`

核心：

1. tactile-derived wrench-aware VLA 预测 reference action 和 future wrench；
2. 冻结 reference VLA；
3. 在线 RL actor-critic 用当前 measured wrench、future wrench cue、VLA tokens、reference actions 做 refinement；
4. intervention-censored critic 防止把人类干预后的成功错误归因给之前的坏动作。

结果：

1. 任务：Coffee Cup、Latch、Egg；
2. 30 次真机评估；
3. π0.5 full task 12/30，ForceVLA 15/30，w/o RL 21/30，TORL-VLA 28/30；
4. 说明 tactile-aware offline policy 还不够，online contact adaptation 很关键。

对我们的启发：

1. online RL 是长期方向；
2. 但短期对我们成本高，需要安全、在线数据、干预协议；
3. 可先做 offline/low-risk 的 final-action trust-region refinement 和 reranking，再把 online RL 作为后续扩展。

### 3.4 AHA-WAM / MemoryVLA++ / WLA / WALL-WM

这批论文说明 VLA 正在向“未来想象 + 长时记忆 + WAM”迁移：

1. AHA-WAM：slow video planner + fast action executor，世界模型低频跑，action 高频闭环；
2. MemoryVLA++：working/episodic memory + world model imagination；
3. WLA：统一 language reasoning、world modeling、action synthesis；
4. WALL-WM：事件级 action/world 建模，反对固定 chunk 造成语义/动作粒度错配。

对我们的启发：

1. 我们不应试图训练大规模 WAM；
2. 我们应把触觉模块放在 high-frequency action correction path；
3. 论文叙事可以借用“future imagination”，但贡献要聚焦 contact consequence。

### 3.5 HapTile / Tabero / MiTaS / RGB-S

这些工作共同支持触觉数据和接触质量评估的价值：

1. HapTile：1,726 demos、38 tasks、9 skills，语言+视觉+触觉+动作；π0 peg insertion 从 vision-only 0% 到 tactile 90%；
2. Tabero：gentle manipulation，decoupled force-position interface，力质量指标超过单纯成功率；
3. MiTaS：多分辨率触觉，五个接触任务，vision-only 31%，visuo-tactile 54%，multi-resolution 80%；
4. RGB-S：把触觉/力投影为 image-aligned saliency，真实遮挡下提升 26.7 个百分点。

对我们的启发：

1. 论文评价不能只报 success rate，必须报 contact quality：
   - force/tactile peak；
   - smoothness；
   - bounce/collision rate；
   - completion time；
   - recovery count；
   - safety threshold violation；
2. 我们的 blackboard/wiping 任务天然适合用接触质量指标；
3. 插座任务可报 bounce risk、pre-bounce score、collision count、成功时间。

## 4. 与我们项目的匹配度

### 4.1 我们已有资源

数据/任务：

1. 插座/peg-in-hole 类接触数据，含 success/bounce；
2. 黑板/wiping 类接触数据，含 force/tactile proxy 和弱标签；
3. 可继续真机采集 baseline-vs-guided rollout。

模型/代码：

1. TactileVAE / tactile latent；
2. latent Foresight；
3. CQF / TacQualityEnergy / task-conditioned scorer；
4. DP candidate / final-action refinement；
5. `action -> Foresight -> tactile decoder -> scorer -> gradient` 工程链路已经 dry-run 通过；
6. 工作记录显示 guided server packet 已可用，但还缺真机 formal validation。

这些资产与最新热点的对应关系：

| 最新热点 | 我们已有资产 | 可形成贡献 |
|---|---|---|
| tactile WAM | latent Foresight | 轻量 tactile consequence predictor |
| force-aware WAM | TacQualityEnergy/CQF | future contact quality energy |
| residual correction | final-action trust-region refinement | 无需 intervention 的 scorer-guided correction |
| failure recovery | risk/quality scorer | runtime monitor + retry/recover trigger |
| WAM real-time | 轻量 tactile latent，不生成视频 | fast action-path guidance |

### 4.2 为什么不建议主做通用 VLA 基座

Qwen-VLA、GEAR-VLA、π0.5、GR00T、OpenVLA-OFT 等方向门槛很高：

1. 需要大规模多机器人数据；
2. 需要强算力；
3. benchmark 竞争激烈；
4. 我们的小规模真机触觉优势无法在通用基座训练中充分体现；
5. 即使做出来，也容易被认为是“又一个微调”。

更合理做法：

1. 以 DP/ACT 或轻量 VLA action head 为 base policy；
2. 将我们的 tactile consequence critic 作为可插拔模块；
3. 后续再接 OpenVLA/pi0/Qwen-VLA 作为更强 base。

## 5. 推荐方向排序

### Rank 1: PTG-VLA / Tac-WAM Lite

全称：

**Proactive Tactile Consequence Guidance for Vision-Language-Action / World Action Policies**

核心问题：

接触密集任务中，VLA/WAM 的动作输出即便视觉上合理，也可能导致未来碰撞、打滑、压力过大、接触不连续。当前 tactile VLA 多数是被动融合，无法在执行前评估候选动作的接触后果。

核心方案：

1. 输入当前视觉/触觉/状态和候选动作；
2. Foresight 预测未来 tactile latent / force proxy；
3. TacQualityEnergy/CQF 对未来接触后果打分；
4. 推理时用三种方式引导动作：
   - Best-of-K reranking；
   - clean-action trust-region gradient refinement；
   - low-score safety gate / recovery trigger。

一句话创新：

> Treat predicted tactile consequences as a critic for action generation, not merely as an auxiliary modality.

为什么容易 work：

1. 我们已有 Foresight 和 scorer；
2. 已有可微 guidance dry-run；
3. 不需要训练大模型；
4. 可先在离线 candidate ranking 上验证，再做真机。

关键对比：

1. DP / ACT / VLA base；
2. + current tactile concat；
3. + future tactile auxiliary loss only；
4. + reranking；
5. + gradient refinement；
6. + recovery/safety gate；
7. 与 Dream-Tac/FAWAM 做定性定位对比。

预期论文贡献：

1. Tactile consequence predictor；
2. Contact quality energy；
3. Runtime action guidance/refinement；
4. Multi-task contact-quality evaluation。

### Rank 2: Contact-Aware Failure Recovery and Safety Filter

核心问题：

VLA 在 off-nominal contact state 中容易反复失败；最近 ProbeAct、Attention Safety Filter、ReCoVLA、B2FF 都说明 runtime recovery 是热点。

我们的方案：

1. 用 tactile quality/risk scorer 做 failure predictor；
2. 当 predicted future tactile risk 高时：
   - 拒绝当前 action；
   - 进入 recovery primitive；
   - 执行 residual correction；
   - 或选择“熟悉未来里程碑”。
3. 不依赖大 VLM 在线推理，低延迟适合真机闭环。

适合作为：

1. Rank 1 主线的 extension；
2. 或者在真机结果足够强时独立成短论文。

### Rank 3: Task-Conditioned Tactile Quality Foundation for Contact Skills

核心问题：

不同接触任务的“好接触”不同：插座要避免 bounce，擦黑板要保持合适压力和柔顺，抓取要避免滑移/过力。

我们的方案：

1. 共享 tactile/action encoder；
2. task-conditioned heads：
   - binary safety；
   - reason/failure mode；
   - continuous quality energy；
3. 用同一 scorer 支持多个任务的 guidance。

注意：

之前工作记录已显示任务无关单头分类器跨任务迁移接近随机，因此必须是 task-conditioned，而不是 naive unified classifier。

### Rank 4: VLA Base Model + Tactile Adapter

可做但不建议优先：

1. 以 OpenVLA-OFT / pi0 / Qwen-VLA 为 base；
2. 添加 tactile latent adapter；
3. 做 tactile instruction-conditioned manipulation。

问题：

1. 工程量大；
2. 短期结果不一定比 DP 强；
3. 容易被 Dream-Tac、ForceVLA、ReTac-ACT 覆盖；
4. 我们的核心优势会被埋在大模型微调里。

## 6. 推荐论文方案

### 6.1 暂定标题

候选：

1. **Proactive Tactile Consequence Guidance for Contact-Rich Robot Manipulation**
2. **Tac-WAM Lite: Tactile Consequence as a Runtime Critic for Vision-Language-Action Policies**
3. **Feel Before Acting: Tactile Foresight-Guided Action Refinement for Contact-Rich Manipulation**
4. **From Tactile Fusion to Tactile Critique: Contact Quality-Guided Action Generation**

最推荐第 1 或第 3。

### 6.2 方法总览

```
Observation o_t = RGB, tactile, proprioception, language/task id
Base policy pi_base(o_t) -> candidate action chunk A

Tactile Foresight:
  z_hat_{t+h} = F_theta(o_t, A)

Contact Quality Energy:
  E = Q_phi(o_t, A, z_hat_{t+h}, task_id)

Runtime Guidance:
  1. reranking: choose argmax_A Q_phi
  2. refinement: A' = A + eta * grad_A Q_phi under trust region
  3. safety/recovery: if Q_phi < tau, trigger recovery
```

### 6.3 关键模块

#### 模块 A: Tactile Consequence Predictor

输入：

1. 当前 tactile latent；
2. 视觉/状态上下文；
3. action chunk；
4. task id。

输出：

1. future tactile latent；
2. 可选 future contact scalar：
   - contact intensity；
   - risk/bounce probability；
   - force proxy；
   - smoothness/roughness proxy。

设计要点：

1. 不追求像素级 tactile reconstruction；
2. 优先 latent prediction；
3. 可以补一个 self-supervised temporal contrastive / JEPA objective；
4. 预测 horizon 根据任务设置：
   - 插座：pre-bounce 前 5-15 steps；
   - 黑板：未来 16-32 steps 的 pressure/smoothness。

#### 模块 B: Contact Quality Energy

输入：

1. z_current；
2. z_future_pred；
3. delta z；
4. action chunk；
5. state；
6. task id。

输出：

1. continuous quality score；
2. binary safe/good；
3. reason/failure mode：
   - insertion: good / bounce risk / too shallow / lateral collision；
   - board: good / too light / too heavy / rough；
4. 可选 confidence/uncertainty。

训练：

1. BCE + ranking loss；
2. hard negative mining；
3. action perturbation negative；
4. task-conditioned multi-head；
5. quality calibration，用于 safety threshold。

#### 模块 C: Runtime Guidance

优先级：

1. **Clean-action trust-region refinement**：已经 dry-run 通过，最接近可上真机；
2. **Best-of-K reranking**：最稳，适合离线和真机候选选择；
3. **Diffusion denoising guidance**：创新强，但工程风险更大；
4. **Recovery trigger**：适合作为最终系统安全层。

建议第一阶段先做 1 和 2。

## 7. 实验规划

### 7.1 阶段 0：离线证据补齐

目标：

证明 scorer/foresight 对候选动作有真实排序能力。

实验：

1. 插座：
   - success vs pre-bounce action chunk；
   - scorer AUC / ranking accuracy；
   - foresight-predicted tactile delta 是否在 bounce 前可分；
   - candidate reranking top-k hit rate。
2. 黑板：
   - good / too_light / too_heavy / rough；
   - force/tactile weak labels；
   - quality score 与真实 force smoothness 相关性；
   - scorer 对 generated negative trajectories 的排序。
3. 跨任务：
   - task-conditioned scorer vs task-agnostic scorer；
   - 已有结果显示 task-agnostic 不行，应正式写入。

通过标准：

1. binary AUC > 0.85；
2. ranking accuracy > 0.75；
3. score 与物理指标 Spearman > 0.5；
4. candidate reranking 在离线指标上显著优于 random/base。

### 7.2 阶段 1：离线 action guidance 验证

目标：

证明 guidance 不只是分类，而能实际改善 action。

实验：

1. 对 DP 生成的 K 个候选做 reranking；
2. 对 final clean action 做 trust-region refinement；
3. 检查：
   - score_delta；
   - action_delta_norm；
   - hard range violation；
   - smoothness；
   - predicted tactile risk；
   - 是否偏离 expert distribution。

已有工作记录显示：

1. 插座和黑板 dry-run gradient 链路已经通过；
2. refined action 没有硬越界；
3. 仍缺真实 rollout。

通过标准：

1. score 提升率 > 80%；
2. hard violation = 0；
3. action_delta_norm 在安全范围内；
4. 离线预测风险降低。

### 7.3 阶段 2：真机小规模 A/B

任务建议：

1. 插座/peg-in-hole：
   - baseline DP；
   - DP + current tactile concat；
   - DP + reranking；
   - DP + trust-region refinement；
   - DP + refinement + safety gate。
2. 黑板擦拭：
   - baseline DP；
   - DP + tactile quality refinement；
   - 测 success + coverage + force quality + roughness。

每个设置：

1. 初期 10 trials；
2. 稳定后 20-30 trials；
3. 必须记录失败原因，不只记录成功率。

关键指标：

插座：

1. success rate；
2. first-attempt success；
3. bounce/collision count；
4. completion time；
5. max tactile/force spike；
6. recovery count。

黑板：

1. coverage / wipe completion；
2. too-light rate；
3. too-heavy rate；
4. roughness；
5. force variance；
6. completion time。

### 7.4 阶段 3：论文级消融

必须消融：

1. no tactile；
2. current tactile only；
3. predicted tactile only as auxiliary loss；
4. predicted tactile + quality scorer；
5. reranking vs gradient refinement；
6. with/without task conditioning；
7. with/without safety gate；
8. horizon ablation；
9. K candidates ablation；
10. scorer input ablation：
    - no action；
    - no delta z；
    - no state；
    - no task id。

论文故事里最关键的消融：

1. **未来触觉预测比当前触觉更早发现风险**；
2. **质量 energy 比二分类概率更适合 guidance**；
3. **推理时 guidance 比训练时辅助预测更有效**；
4. **task-conditioned scorer 比 task-agnostic scorer 更可靠**。

## 8. 关键设计问题，需要讨论拍板

这些问题建议我们后续单独讨论，不建议我直接替你拍板：

1. **主任务选择**：
   - 只做插座，故事更聚焦；
   - 插座 + 黑板，能证明 task-conditioned contact quality；
   - 再加一个简单擦拭/推压任务，论文更像通用 contact-rich。
2. **base policy 选择**：
   - DP：当前最容易 work，候选多样性强；
   - ACT：已有基础但候选多样性弱；
   - OpenVLA/pi0：更贴近 VLA 热点，但工程风险大。
3. **guidance 形式**：
   - 先主打 clean-action trust-region refinement；
   - 还是主打 best-of-K reranking；
   - diffusion denoising guidance 是否作为创新点加入。
4. **是否使用语言/VLA 名义**：
   - 如果实际任务语言很简单，可以把语言作为 task id / instruction conditioning；
   - 不建议为了“VLA”强行引入大语言模型，除非接 OpenVLA/pi0 做 baseline。
5. **是否引入 force sensor**：
   - 如果当前任务有 wrist force，建议作为评估/弱标签，不一定作为 policy 输入；
   - 我们的核心仍应是 tactile latent + quality energy。

我的建议：

1. 第一篇主线：插座 + 黑板两个任务；
2. base policy：DP；
3. guidance：clean-action trust-region refinement + best-of-K reranking；
4. language：使用 task instruction/task id，先不接大 VLM；
5. 论文定位：VLA/WAM-compatible tactile guidance，不声称训练了 foundation VLA。

## 9. 预期论文结构

### Abstract 关键词

contact-rich manipulation, tactile foresight, tactile consequence, world action model, runtime action guidance, contact quality energy.

### Introduction 逻辑

1. VLA/WAM 在通用操作中表现强；
2. 接触任务失败常由视觉不可见的未来接触后果导致；
3. 现有 tactile VLA 多被动融合触觉，或者把 future prediction 当辅助训练；
4. 我们提出 proactive tactile consequence guidance：
   - predict future tactile consequence；
   - evaluate contact quality；
   - refine/select actions at runtime。

### Method

1. Tactile latent representation；
2. Action-conditioned tactile foresight；
3. Task-conditioned contact quality energy；
4. Runtime action guidance：
   - reranking；
   - trust-region refinement；
   - safety gate。

### Experiments

1. 离线 foresight / scorer 质量；
2. 离线 candidate ranking / refinement；
3. 真机插座；
4. 真机黑板；
5. 消融；
6. contact quality analysis。

### Claims

1. 预测未来触觉比当前触觉更能提前识别失败；
2. 接触质量 energy 能提供可用动作梯度；
3. 轻量 runtime guidance 能显著提升接触任务质量；
4. task-conditioned 设计支持多接触任务。

## 10. 风险与规避

| 风险 | 表现 | 规避 |
|---|---|---|
| Foresight 预测不准 | guidance 误导动作 | 使用 trust-region、小步 refinement、uncertainty gate |
| scorer 学到 action shortcut | 离线高分但真机不泛化 | action dropout、tactile delta 主导、hard negatives |
| 只提升 score 不提升真机 | reward hacking | 必须做真机 A/B 和物理指标 |
| base DP 候选不够好 | reranking 没有好候选 | 加 K、提升 DP、多样性训练 |
| 黑板弱标签噪声 | scorer 不稳定 | 用 force/tactile 多指标 label smoothing |
| 被 Dream-Tac/FAWAM 覆盖 | 创新不明显 | 强调 lightweight runtime critic，而非 heavy joint WAM |

## 11. 最小可行路线

### Week 1

1. 固化 scorer/guidance 离线评估脚本；
2. 生成插座/黑板统一 candidate manifest；
3. 报告 scorer AUC、ranking、score-action gradient sanity；
4. 选定真机任务和 trial protocol。

### Week 2

1. 插座 10-trial A/B：
   - DP baseline；
   - DP + refinement；
2. 黑板 10-trial A/B：
   - DP baseline；
   - DP + refinement；
3. 记录成功率和接触质量。

### Week 3

1. 加 reranking；
2. 加 safety gate；
3. 做 ablation；
4. 如果真机趋势明显，扩大到 20-30 trials。

### Week 4

1. 整理实验图表；
2. 写 method；
3. 写 related work；
4. 补外部 baseline 定位。

## 12. 最终建议

建议立刻推进：

1. **主线名称**：Proactive Tactile Consequence Guidance；
2. **核心实验**：插座 + 黑板，baseline-vs-guided 真机；
3. **核心模块**：Foresight + TacQualityEnergy + trust-region refinement；
4. **论文定位**：WAM/VLA-compatible runtime tactile critic；
5. **短期目标**：先证明真实接触质量改善，再考虑接 OpenVLA/pi0。

不建议当前立刻做：

1. 从零训练 Qwen-VLA/OpenVLA 触觉大模型；
2. 大规模 tactile dataset 论文；
3. 纯 WAM 视频生成；
4. 纯推理加速；
5. 没有真机验证的纯离线 scoring 论文。

最关键的下一步不是再调研，而是补真机 A/B：

> 只要插座或黑板任一任务上，guided policy 能稳定降低 bounce/roughness/force violation，同时成功率不下降，这条线就非常值得继续推进。
