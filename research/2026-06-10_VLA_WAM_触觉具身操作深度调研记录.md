## 重点论文抽取与阅读

时间：2026-06-09 21:20-22:20 CST

下载/抽取 PDF：

1. `2606.08737` Dream-Tac: A Unified Tactile World Action Model for Contact-Rich Robot Manipulation
2. `2606.08555` FAWAM: Force-Aware World Action Models for Closed-Loop Contact-Rich Manipulation
3. `2606.09337` TORL-VLA: Tactile Guided Online Reinforcement Learning for Contact-Rich Manipulation
4. `2606.09811` AHA-WAM: Asynchronous Horizon-Adaptive World-Action Modeling with Observation-Guided Context Routing
5. `2606.09827` MemoryVLA++: Temporal Modeling via Memory and Imagination in VLA
6. `2606.04825` HapTile: A Haptic-Informed Vision-Tactile-Language-Action Dataset

重点阅读点：

1. Dream-Tac：
   - 统一预测 future visual、future tactile、actions；
   - contact-gated visuotactile fusion；
   - contact-aware attention bias；
   - 六个真机接触任务，平均成功率 83.3%，visual WAM 51.7%，visuo-tactile WAM 74.2%；
   - 最大价值：证明 tactile WAM 是很新的热方向；
   - 对我们的启发：我们不能只跟随做 unified tactile WAM，应该强调 lighter runtime action guidance / verifier / correction。
2. FAWAM：
   - force at perception, prediction, execution 三层利用；
   - joint action-force prediction；
   - predicted wrench reference + real wrench error 做 residual correction；
   - 四个真机任务平均 85%，仅加 force obs 56.25%，joint prediction 73.75%，full 85%；
   - 对我们的启发：未来触觉/力预测必须服务于 execution-time correction，不能只是 auxiliary loss。
3. TORL-VLA：
   - tactile-derived wrench-aware VLA + online RL refinement；
   - 30 次真机评估，full task 从 pi0.5 的 12/30 提升到 28/30；
   - 对我们的启发：长期路线可以加入在线 RL，但短期不建议优先，因为数据和安全成本高。
4. AHA-WAM：
   - slow video planner + fast action executor；
   - observation-guided context routing；
   - 24.17Hz 到 56.9Hz 的闭环速度；
   - 对我们的启发：我们的触觉预测/质量判断应尽量放在 fast action path，而非重视频生成 path。
5. MemoryVLA++：
   - memory + imagination；
   - 多 benchmark、多机器人、长时序；
   - 对我们的启发：可在论文中借“future imagination”叙事，但我们不应试图复现大规模 memory VLA。
6. HapTile：
   - 1,726 demos、38 tasks、9 skills；
   - 语言、视觉、触觉、动作、haptic feedback；
   - π0 在 peg insertion 从 vision-only 0% 到 tactile 90%；
   - 对我们的启发：如果公开数据可用，可作为外部验证/预训练补充，但主论文仍应以自有真机触觉数据为核心。

## 当前调研结论快照

最推荐方向：

1. Tac-WAM / Proactive Tactile Guidance for VLA/WAM：
   - 用 action-conditioned tactile/force foresight 预测候选动作后果；
   - 用 tactile quality energy / CQF 评估未来接触；
   - 推理时做动作筛选、梯度修正和安全门控；
   - 叙事：不是 tactile fusion，而是 tactile consequence as critic。
2. Contact-aware VLA failure recovery / safety filter：
   - 检测未来接触风险；
   - 当 risk high 或 score low 时触发 residual recovery 或 retry；
   - 可作为主线的 extension，也可独立成短论文。
3. Task-conditioned tactile quality model：
   - 统一插座/黑板/擦拭等任务，构建共享触觉质量 taxonomy；
   - 不做任务无关单头分类器，而做 task-conditioned quality energy。

不优先方向：

1. 从零训练/大规模预训练通用 VLA；
2. 只做 OpenVLA/pi0/Qwen-VLA 触觉输入拼接微调；
3. 纯 WAM 推理加速；
4. 纯数据集论文，除非能快速扩展到多任务规模。
