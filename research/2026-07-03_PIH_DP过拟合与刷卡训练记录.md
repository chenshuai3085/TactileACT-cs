# 2026-07-03 PIH/Card 官方纯视觉 DP 过拟合排查与刷卡训练记录

## 当前结论

前面 PIH 官方纯视觉 DP 的 validation loss 很早到达最优，然后 train loss 继续下降、val loss 回升，更像是小数据/小验证集上的过拟合和验证噪声叠加，不是单一代码 bug。

主要原因：

- 验证集太小：260625 使用 5% val 时只有 4 条 episode，260630 使用 5% val 时只有 5 条 episode，单条轨迹差异会明显影响 val MSE。
- 滑窗样本数看起来很多，但相邻窗口高度重叠，独立 episode 多样性仍然少。
- 模型容量大：ResNet18 per-camera + 1D UNet 对几十到一百条 episode 来说容易记住训练分布。
- train/val 图像增强不完全一致：train 是 random crop，val 是 center crop，val loss 不等同于真实 rollout 成功率。
- diffusion val loss 是随机 timestep/noise 的 MSE，当前脚本评估的是非 EMA 在线权重，短期波动正常。

## 后续训练策略

- 继续保留 `dp_best.pth` 作为主要候选，不根据后期更低 train loss 的 top-k checkpoint 直接部署。
- 对少量 episode 的新任务，val ratio 从 5% 提高到 10%-15%，让验证集至少有 3 条以上 episode。
- 训练监控上至少观察到 200 epoch；如果 200-300 epoch 之间 val 长期不刷新且 train/val gap 扩大，就停止并保留 best。
- 若要更稳定比较，可后续加固定 noise/timestep 的 eval 或 EMA eval；这属于评估增强，不影响当前先训 baseline。

- 使用：`/media/chenshuai/EXTERNAL_USB/pih_dataset/260629_v8j_card/peg_in_hole_0629/success`

## 关于 TactileVAE

纯视觉官方 DP 不需要 TactileVAE。

如果后续要做 tactile+vision DP、foresight 或引导，则建议为刷卡任务单独训练 card-specific TactileVAE，再训练 policy / foresight / scorer。不要直接复用擦黑板 VAE 作为最终版本，因为接触形态和 marker 分布不同。
