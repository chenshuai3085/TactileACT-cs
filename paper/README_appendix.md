# ForeTac RA-L Appendix Source

Compile entry:


This appendix is a standalone supplementary-material document using the same
`ieeeconf.cls` template as the main RA-L draft. Upload
`ForeTac_RAL2026_appendix_source.zip` to Overleaf and set `appendix.tex` as the
main file.

Included evidence:

- data format and current local data inventory
- TacVAE / encoder reconstruction comparison
- action-conditioned foresight horizon table
- preference-order scorer validation table
- guidance diagnostic table and visualization
- board, vase, and socket insertion force-curve analysis
- main comparison and ablation tables

Open items are kept as `TBD` in the appendix where final rollout data or figures
are not yet available.
