# Suggested captions

## Wiping sequence

**Tactile marker displacement during board wiping.** Yellow arrows visualize
the measured 2D displacement of the left tactile sensor's `9x9` marker array
relative to a no-contact reference frame. Contact onset produces a small
coherent shear field, which grows during stable wiping and reaches its largest
magnitude at peak shear. Arrow lengths use the original pixel scale without
visual magnification.

## Contact-mode comparison

**Tactile deformation fields under different board-contact modes.**
Insufficient pressure produces little marker motion; stable wiping yields a
moderate coherent field; excessive pressure causes the largest deformation;
and the oscillation sample exhibits a large frame-to-frame change. The
condition names are collection-condition proxies rather than manually
annotated per-frame contact states. Yellow arrows show displacement from each
episode's no-contact reference frame at the original pixel scale.
