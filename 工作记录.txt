2026-04-16  TFAC V4 (LDG) 完整实现
---------------------------------------------------------------
任务: 基于 V3 问题分析和论文调研，设计并实现 TFAC V4 (TFAC-LDG)
目标: CoRL 2026 论文, 故事线 Think → Dream → Verify → Act

【V3 五大问题】
1. 单 token 触觉瓶颈: 81个标志点压缩到1个token，空间结构丢失
2. 只用最后帧: 10帧预测只取 frame[9]，中间帧信息浪费
3. A1 完全 detach: foresight 质量无法反传到 draft action
4. 弱对比学习: 63个负样本, GT contrastive 禁用, lambda=0.1
5. SpatialTactileDecoder: 从单一全局向量重建 9×9 损失大

【V4 五大创新 (C1-C5)】
C1: SpatialMarkerEncoder — 9 spatial patch tokens
   - (B,9,9,2) → per-point MLP(4→64→128→D) → +pos_embed → 2-layer SelfAttn → 3×3 patch_pool → (9,B,D)
   - 保留空间结构，支持per-patch对比学习

C2: Latent Prediction + Dynamic-Aware Weighted Loss
   - 在潜在空间监督: encode GT marker → spatial tokens → smooth_l1 vs predicted tokens
   - 动态权重: weight = sqrt(change/mean_change)，变化大的帧权重更大

C3: Tactile Consistency Loss (核心创新)
   - 动作→触觉因果验证: TactileDynamicsModel 预测 z_next
   - Margin ranking: sim(z_pred, z_gt_next) > sim(z_pred, z_random) by margin=0.2
   - 验证 foresight 预测的触觉轨迹与实际动力学一致

C4: Temporal Differential Residual Action
   - A2 = A1 + sigmoid(alpha) * deltaA
   - alpha 可学习，初始化 0.1 (sigmoid ≈ 0.525)
   - TactileTrajectoryEncoder: 时序差分编码 [frame0, diff1, diff2, ...] → summary

C5: Multi-level Contrastive Learning
   - Spatial: per-patch InfoNCE, (B,9,D) vs (B,D) → B*9 负样本
   - Temporal: margin ranking, 相邻帧 > 远距帧
   - GT alignment: 预测视觉 vs GT视觉 标准 InfoNCE

【核心问题】
Ablation2 的 gate_traj 在 GT curriculum 阶段持续下降 (0.34→0.28)

2026-04-16  V4 深度分析 + FiLM 融合实现
===============================================================
【V4 失败根因分析】

1. SpatialMarkerEncoder 空间 tokens 无法有效传递到 action:
   - Gate fusion: 9个空间tokens必须mean-pool→1个向量才能gate → 空间信息丢失
   - Token fusion: 9个tokens添加到210+个memory tokens → ~4%注意力容量, 被稀释
   - 结论: 空间 tokens 的优势被融合方式彻底消解

2. 对比学习温度爆炸 (V1和V4都有此问题):
   - log_temp 无约束, 从 0.07 涨到 16+ → InfoNCE loss 退化为常数
   - V1 成功不依赖对比学习 (V1也温度爆炸但仍达到0.072)
   - 修复: clamp log_temp to [-2, 2]

3. V4 过拟合更严重 (118M params vs V1 114M):
   - SpatialMarkerEncoder 额外参数 + SelfAttn 增加了过拟合风险
   - 小数据集(337 episodes)不足以支撑更大模型

【FiLM 融合设计 (Foresight-conditioned Adaptive Layer Modulation)】

核心思路: 不修改 memory, 在 decoder_final 每层后用 foresight 特征调制隐状态。
  output = output * (1 + γ_i(z_foresight)) + β_i(z_foresight)

设计优势:
  1. 细粒度条件化: 7层decoder每层独立的γ/β, 比gate的1次全局融合更精细
  2. 渐进学习: γ/β零初始化, 训练初期≈恒等映射, FiLM信号逐步增强
  3. 不增加memory维度: 不像token fusion添加额外token导致注意力稀释
  4. 兼容gate: gate_film模式同时保留gate融合 + FiLM调制

实现方式:
  - "film" mode: memory不变, 仅靠FiLM调制
  - "gate_film" mode: gate融合enriched memory + FiLM双重条件化
  - 新增 _run_decoder_with_film() 方法替代 _run_decoder()
  - 参数量: film=114.71M, gate_film=118.13M

【同步修复】
  - contrastive temperature clamp: log_temp.clamp(-2, 2)
  - latent foresight loss: smooth_l1(predicted_encoded, GT_encoded.detach()), λ=0.3
  - train.py: 添加 lambda_latent_foresight 参数传递

【验证】
  - film 和 gate_film 两种模式均通过 shape test (scripts/test_film.py)
  - 所有loss正常, 形状正确, inference输出正确

【Gate Fusion 核心问题分析】

Gate fusion 的数学本质:
  fused[i] = w_mem * mem[i] + w_fut * fut + w_a1 * a1
           = 0.33 * mem[i] + 0.33 * fut + 0.33 * a1
           = 0.33 * mem[i] + constant_bias

三大问题:
  1. Memory 信号衰减 67%: 空间信息被严重削弱
  2. Foresight 信息是 rank-1: 所有位置收到相同的 future 向量
  3. 无空间选择性: 所有 memory 位置统一加权

验证: V1 0401 foresight_tac=0.004 (预测质量极好) 但 A2 仅提升 10%
  Pearson 相关 r=-0.119: foresight 质量与 A2 提升几乎不相关
  → 瓶颈在 fusion 机制, 不在预测质量

FiLM 的优势:
  layer_out = layer_out * (1 + gamma(fut)) + beta(fut)
  1. Memory 全强度保留 (不被缩放)
  2. 7层独立 gamma/beta → 更细粒度条件化
  3. 调制 decoder 计算, 不修改输入
  4. 零初始化 → 渐进学习, 不影响早期训练
